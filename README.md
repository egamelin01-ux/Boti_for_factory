# Боты «Контент-цеха» — европейская машина

Живут на `157.228.142.176` (`my-bot001`), потому что **из России недоступны ни
Telegram, ни Anthropic**: боевой сервер портала до `api.telegram.org` не
достаёт вовсе. Всё, что общается с Telegram, работает отсюда.

## Что здесь

| Файл | Служба | Что делает |
|---|---|---|
| `notify-bot.mjs` | `notify-bot` | **ИИнна**: напоминания клиентам о несогласованном, привязка чатов к проектам, приём команд портала (порт 8787) |
| `reader-bot.mjs` | `reader-bot` | **ИИнокентий**: читает рабочие чаты, сохраняет вложения, ловит ссылки на созвоны, напоминает владельцу о неотвеченном, мост уведомлений сотрудникам (порт 8788) |
| `audit-coverage.mjs` | `audit-coverage.timer` | ежедневная сверка: у живого проекта есть чат, в чате есть ассистент |
| `transcribe-pending.py` | `transcribe.timer` | расшифровка голосовых локальной моделью (faster-whisper, medium) |
| `bot.mjs` | — | старый мост Claude Code в Telegram, выключен 28.08.2026 |

## Чего здесь нет и почему

- `.env` — токены и секреты, только на машине (`chmod 600`). Образец: `.env.example`.
- `*-state.json`, `reader-log.ndjson`, `media/`, `imports/` — данные, а не код:
  привязки чатов, смещения опроса, переписка с расшифровками, вложения.
- `stt-model/` — модель распознавания, 1,5 ГБ, скачивается сама.

## Как выкатывать

Правки здесь применяются перезапуском службы — сборки нет:

```bash
node --check reader-bot.mjs && systemctl restart reader-bot
node --check notify-bot.mjs && systemctl restart notify-bot
```

Проверить после перезапуска: `systemctl is-active reader-bot notify-bot`, лог —
`/var/log/reader-bot.log`, мост — `curl -s localhost:8788/health`.

## Важное об устройстве

- **Вебхуков нет ни у одного бота.** Telegram не даёт боту вебхук и длинный
  опрос одновременно, а опрос нужен ИИнокентию для чтения чатов. Привязка
  сотрудников идёт через `/start <код>` в личке, бот сверяет код с порталом.
- **ИИнокентий не пишет в группы.** Мост принимает только положительные
  `chat_id` — лички. Это свойство кода, а не договорённость.
- **Группы превращаются в супергруппы**, когда боту дают права администратора,
  и меняют id. ИИнна переносит привязку сама — по ответу Telegram и по
  служебному сообщению, с обеих сторон.
